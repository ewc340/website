An opinionated markdown pipeline that pairs GFM footnotes with per-post BibTeX bibliographies. Extracted from this site's content engine so other static sites can adopt the same authoring model.

Supports APA/Chicago/Vancouver styles via CSL, with per-post overrides in frontmatter.
